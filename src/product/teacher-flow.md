# Для преподавателя

Преподаватель работает в панели администратора.

## Наборы слов

Преподаватель указывает имя набора и языки, которые в нём используются.
Набор привязан к конкретному преподавателю и по умолчанию недоступен
никому, кроме него.

Преподаватель может редактировать свои наборы, добавляя,
изменяя или удаляя слова (или удалить набор целиком).

Для каждого слова в наборе преподаватель указывает:

- значение на первом языке;
- значение на втором языке;
- если требуется, пояснение значения слова.

## Группы и ученики

Преподаватель создаёт группу, указав её название/описание,
и приглашает в неё учеников. Изначально у группы пустой список
доступных наборов, который можно редактировать по своему усмотрению
(добавляя туда ссылки на свои наборы или убирать их).

Преподаватель может удалить свою группу по своему усмотрению.
