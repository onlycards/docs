# Глоссарий

## Преподаватель

Преподаватель имеет доступ к панели администратора,
где работает со своими данными. Доступ к данным преподавателя
есть только у этого преподавателя.

## Ученик

Ученик может быть приглашён преподавателем в группу (по ID).
Ученик работает только с данными, доступными его группам.

## Группа

Преподаватель создаёт группы для работы с учениками. Индивидуальное
обучение — это группа из одного ученика.

## Набор слов

Преподаватель создаёт свои наборы слов — множества пар слов на двух языках.
Каждой своей группе можно выдать (или забрать) доступ к любому своему
набору слов.
