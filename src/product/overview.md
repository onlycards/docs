# Что такое OnlyCards

Приложение OnlyCards придерживается
[главного принципа Unix](https://ru.wikipedia.org/wiki/Философия_Unix):
**делай одну вещь, но делай её хорошо**. В конечном счёте, функциональность
OnlyCards сводится к одному: запоминанию иностранных слов по карточкам.

Отсюда и название: **только карточки** и ничего лишнего.

## Предназначение

OnlyCards помогает преподавателям иностранных языков выдавать ученикам
наборы слов, а ученикам — запоминать эти слова по карточкам.

## Для кого

- для преподавателей иностранных языков;
- для учеников;
- для небольших учебных групп, курсов и частных занятий.

## Как это работает

1. Преподаватель создаёт группу.
2. Добавляет учеников.
3. Создаёт набор слов.
4. Выдаёт группе доступ к набору.
5. Ученики изучают слова по карточкам.
