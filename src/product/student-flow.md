# Для ученика

Ученик работает в интерфейсе приложения.

## Группы

Сначала необходимо попасть в группу. Для этого следует сообщить преподавателю
свой ID. Преподаватель отправляет приглашение, ученик принимает его:
теперь ученик числится в группе.

## Изучение слов

Ученик видит все наборы слов, доступные всем группам, в которых он числится.

Для тренировки можно выбрать любое количество доступных наборов.
Можно выбрать, какой стороной вверх карточки изначально будут расположены. 

Слова приходят в случайном порядке в виде карточек: на разных сторонах карточки
одно и то же слово на разных языках. Для текущей карточки можно сделать выбор:
хорошо знаешь это слово или нет. Если выбрал, что слово пока что изучено
недостаточно хорошо, оно скоро придёт вновь. Иначе — отправится в конец колоды.

Карточки зациклены, тренировка может продолжаться неограниченное время.
Чтобы завершить тренировку, необходимо явно из неё выйти.
